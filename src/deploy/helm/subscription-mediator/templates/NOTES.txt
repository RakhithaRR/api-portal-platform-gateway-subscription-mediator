subscription-mediator {{ include "subscription-mediator.imageVersion" . }} is deployed as Deployment {{ .Release.Namespace }}/{{ $fullname }} ({{ .Values.replicaCount }} replicas).

1. Register this webhook targetUrl with the API Portal subscriber:

     http://{{ $fullname }}.{{ .Release.Namespace }}.svc:{{ .Values.service.port }}/devportal/events

   The secret registered there must equal the webhook secret in Secret
   {{ .Release.Namespace }}/{{ include "subscription-mediator.secretName" . }}.

2. Check it is up and has reached the gateway:

     kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ $fullname }}
     kubectl -n {{ .Release.Namespace }} logs deployment/{{ $fullname }}
     helm test {{ .Release.Name }} -n {{ .Release.Namespace }}

3. /status is unauthenticated and reachable only inside the cluster. Its
   counters are per pod. Use a port-forward:

     kubectl -n {{ .Release.Namespace }} port-forward svc/{{ $fullname }} 8085:{{ .Values.service.port }}
     curl -s localhost:8085/status
